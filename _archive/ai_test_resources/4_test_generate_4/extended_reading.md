### 🧭 进阶阅读：从 Java 基础向工程深处漫溯

当你熟悉了 Java 的语法、面向对象和集合框架后，不妨将视野投向更具工程价值的「高阶概念」，这些能力会直接决定你程序设计的上限。

**🔹 泛型与类型擦除**  
基础课程中的 `ArrayList<String>` 只是起点。建议你深入理解类型擦除机制、通配符（`? extends` / `? super`）的使用场景，学会利用 PECS 原则（Producer Extends, Consumer Super）设计更灵活的 API。这能帮助你写出类型安全且可复用的代码，真正理解为什么“泛型是编译期的语法糖”。

**🔹 函数式编程与 Stream 流**  
Lambda 表达式与方法引用不只是让代码变短。建议探索 `java.util.function` 包中的函数式接口，并重点掌握 Stream 的惰性求值、`map`-`filter`-`reduce` 模型及并行流的适用边界。这将彻底改变你对数据处理的思维模式。

**🔹 注解与运行时反射**  
超越 `@Override`，学会定义自定义注解并结合反射在运行时读取注解信息。这是无数 Java 框架（Spring、JUnit、Jackson）的运作基石。了解 `Class` 对象、`Method` 和 `Field` 的反射操作，是理解控制反转和依赖注入的前提。

**🏭 真实项目中的影子**  
- **泛型无处不在**：自定义通用缓存、DAO 层基类的设计与类型约束。  
- **Stream 大显身手**：对电商订单列表进行多条件筛选、分组统计与并行汇总。  
- **注解驱动开发**：使用 JPA 注解映射数据库表、结合 AOP 记录操作日志或实现权限校验。

**📚 进一步学习资源方向**  
- 《Effective Java》：约书亚·布洛赫的经典，提供大量上述概念的实践箴言。  
- Java 官方教程的「Collections」与「Reflection API」专题。  
- 动手阅读小型框架（如 NanoHTTPD 或简易 DI 容器）的源码，观察基础概念如何组合成实用工具。
