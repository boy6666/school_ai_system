### 拓展阅读：从 Java 基础走向实战深处

你已经掌握了变量、循环、面向对象等 Java 基础，下一步可以关注这些让代码更优雅、更可靠的进阶概念。

**1. 泛型与类型擦除**  
基础中的 `ArrayList` 其实就用到了泛型。泛型让代码在编译期就能捕获类型错误，避免运行时的 `ClassCastException`。但 Java 的泛型通过“类型擦除”实现，很多限制由此而来。理解通配符（`? extends`、`? super`）、泛型方法与类型边界，能读懂并设计出更安全的集合与工具类。

**2. 注解与反射**  
从 `@Override` 起步，到自定义注解，注解本身只是元数据。配合反射机制，可以在运行时动态获取类信息、创建对象、调用方法。这是大量框架（如 Spring、JUnit）的基石，理解它们能让你看清“魔法”背后的原理。

**3. 函数式编程与 Stream API**  
Java 8 引入的 Lambda 表达式和 Stream，让集合操作从命令式转向声明式。学会将 `filter-map-reduce` 组合成流水线，不仅能减少循环和临时变量，还天然适合并行处理，是处理数据的现代方式。

**实际项目应用场景**  
- **用户数据筛选与统计**：使用 Stream 从百万级用户列表中过滤活跃用户、按地区分组并计算平均消费，代码简洁且可轻松转为并行流提升性能。  
- **简易 Web 框架**：通过注解标记 URL 映射，用反射自动分发请求到对应方法，体会 Spring MVC 的核心思路。  
- **通用数据访问层**：利用泛型封装增删改查操作，让 `UserDao` 和 `OrderDao` 共享一套类型安全的基类，减少重复代码。

**进一步学习资源方向**  
- **书籍**：《Effective Java》是必读进阶经典，深入探讨最佳实践；《Java 核心技术 卷 II》覆盖流、网络、安全等高级特性。  
- **开源项目**：阅读小型的 Java Web 框架源码（如 Javalin、Blade），观察注解、反射和流如何协同工作。  
- **文档与实践**：Oracle 官方教程的泛型和集合部分值得细读；在 LeetCode 或实际数据处理任务中刻意使用 Stream、Optional 代替传统写法，逐步内化新思维。
