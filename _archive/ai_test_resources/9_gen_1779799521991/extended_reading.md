## 拓展阅读：从 Java 基础走向工程实践

掌握变量、循环、面向对象等基础语法后，你可以通过以下进阶概念进一步理解 Java 的设计精髓，并了解它们在实际项目中的价值。

### 1. 泛型与类型安全
泛型让类或方法在定义时不指定具体类型，而在使用时才确定。它能在编译期发现类型错误，避免运行时的 `ClassCastException`。  
**应用场景**：集合框架大量使用泛型，如 `List<Order>` 存储订单对象；在 DAO 层封装通用增删改查时，通过泛型避免重复代码。  
**延伸资源**：《Effective Java》中“泛型”章节；Oracle 官方教程《Generics》。

### 2. Lambda 表达式与函数式编程
Java 8 引入的 Lambda 让你可以用更简洁的方式传递行为，配合 `Stream` API 实现声明式数据处理，大幅减少样板代码。  
**应用场景**：对订单列表按金额过滤、排序、统计；在 GUI 中为按钮绑定事件；在 Spring WebFlux 中构建响应式流水线。  
**延伸资源**：《Java 8 实战》；Baeldung 网站的“Java 8 Streams”系列。

### 3. 异常处理与日志规范
从基础的 `try-catch` 进阶到区分检查型与非检查型异常、自定义业务异常，再结合 SLF4J/Logback 输出关键信息，是编写健壮应用的必备技能。  
**应用场景**：远程调用失败重试、事务回滚、全局异常拦截器统一返回前端错误信息，并能通过日志快速排障。  
**延伸资源**：《阿里巴巴 Java 开发手册》异常与日志章节；SLF4J 官方文档。

**下一步学习路径建议**：先阅读《On Java 8》巩固进阶特性，然后通过 Spring Boot 实战项目（如个人博客、电商后台）串联知识，最终可深入 JVM 调优与并发编程。
