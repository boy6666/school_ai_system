# 递归与二叉树基础

递归是一种函数直接或间接调用自身的编程思想，常用于解决可以分解为相似子问题的问题。
递归必须包含两个关键部分：递归出口和递归递推关系。

在二叉树中，很多问题都可以用递归处理，例如前序遍历、中序遍历、后序遍历、求树高和判断节点是否存在。

## 常见错误

1. 忘记递归出口，导致无限递归。
2. 没有处理空节点。
3. 不能区分当前层逻辑和下一层递归逻辑。
4. 不理解调用栈的返回过程。

## Java 示例

```java
int height(TreeNode root) {
    if (root == null) return 0;
    return Math.max(height(root.left), height(root.right)) + 1;
}
```

## 四、易错点

1. 没有明确基本情况或边界条件。
2. 只会背模板，不理解执行过程。
3. 无法把题目拆成子问题。
4. 代码实现时忽略空值或极端输入。
