# 控制台测试用例

## 测试目的
验证 `School AI System` 的画像构建、资源生成、学习路径规划以及 Guardrails 校验功能。

## 测试用例

### 用例1：正常计算机学生（完整描述）
**输入**：

我是计算机专业大二学生，正在学习数据结构。链表我学得还行，但递归和二叉树总是搞不懂。我希望有图解、动画和代码练习。学习目标是期末考试85分。

text

```
**预期结果**：
- 画像包含8个字段，且字段值非空。
- 资源包含5类，每类内容非空。
- 学习路径5步，每步包含 step, title, resource, reason。
- 最终生成文件保存在 `data/resources/test_normal/`。

**校验方式**：运行 `test_console.py` 自动验证。

---

### 用例2：极简输入（触发兜底）
**输入**：
```



学递归

text

```
**预期结果**：
- 画像使用默认值补全缺失字段。
- 生成资源完整，不报错。
- 易错倾向、资源偏好有默认内容。

---

### 用例3：跨专业文科生学Python
**输入**：
```



我读历史系，想自学Python用于文本分析。已经会循环和函数，但对类和对象不懂。需要实际项目案例。

text

```
**预期结果**：
- 画像中 `major` 为“历史系”或“历史专业”，`course` 含“Python”。
- 资源中包含课程讲解、代码实践等。

---

### 用例4：空输入（应被拦截）
**输入**：
``` (空字符串) ```

**预期结果**：
- 程序应提示输入不能为空，不调用图流程。

---

### 用例5：极端长文本（500字）
**输入**：
```



（构造约500字的详细学习需求，包含多个薄弱点、学习偏好、目标等）

text

```
**预期结果**：
- 正常处理，无截断错误。
- 生成的文件大小合理。
