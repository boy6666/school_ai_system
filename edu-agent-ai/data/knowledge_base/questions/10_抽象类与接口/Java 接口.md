1. 在 Java 中，定义接口使用的关键字是？
   A. class
   B. interface
   C. implements
   D. extends
   **答案：B**
2. 接口中的成员变量默认的修饰符是？
   A. public static final
   B. private static final
   C. public abstract
   D. protected static
   **答案：A**
3. 以下关于接口的说法，正确的是？
   A. 接口可以实例化对象
   B. 接口中可以有非抽象方法
   C. 类实现接口时使用 implements 关键字
   D. 接口只能继承一个接口
   **答案：C**
4. 一个类实现多个接口时，接口之间用什么符号分隔？
   A. 分号
   B. 逗号
   C. 空格
   D. 冒号
   **答案：B**
5. 接口与抽象类的区别，错误的是？
   A. 抽象类可以有构造方法，接口没有
   B. 接口只能有常量，抽象类可以有成员变量
   C. 接口中的方法默认是 public abstract
   D. 类可以实现多个抽象类
   **答案：D**
