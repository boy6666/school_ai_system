1. Java 中一个子类可以继承多少个父类？
   A. 1 个
   B. 2 个
   C. 任意多个
   D. 0 个
   **答案：A**
2. 哪个关键字用于实现接口的多继承？
   A. extends
   B. implements
   C. inherit
   D. using
   **答案：B**
3. 子类构造方法中，如果没有显式调用 super(...)，则默认调用？
   A. 父类无参构造器
   B. 父类有参构造器
   C. 会编译错误
   D. 调用父类私有构造器
   **答案：A**
4. final 修饰的类有什么特性？
   A. 可以被子类继承
   B. 不能有实例
   C. 不能被继承
   D. 必须被继承
   **答案：C**
5. 关于 super 关键字，正确的是？
   A. 可以访问父类的私有成员
   B. 用于调用父类构造方法
   C. 只能在子类的构造方法中使用
   D. 可以代替 this
   **答案：B**
