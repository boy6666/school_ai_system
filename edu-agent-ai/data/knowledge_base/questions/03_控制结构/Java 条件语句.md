1. 在 if-else 语句中，如果 if 的条件为 false，则执行？
   A. if 语句块
   B. else 语句块
   C. 继续执行下一行
   D. 抛出异常
   **答案：B**
2. 以下哪个是正确的嵌套 if 写法？
   A. if (x>0) { if (y>0) { } }
   B. if (x>0) if (y>0)
   C. 两者都可
   D. 两者都错
   **答案：C**
3. 下列代码输出结果？

java

```
int score = 75;
if (score >= 90) {
    System.out.print("A");
} else if (score >= 80) {
    System.out.print("B");
} else if (score >= 70) {
    System.out.print("C");
} else {
    System.out.print("D");
}
```



A. A
B. B
C. C
D. D
**答案：C**

4.以下关于 else 的说法正确的是？
A. 每个 if 必须跟一个 else
B. else 必须与最近的 if 配对
C. else 可以独立存在
D. else 后面不能有花括号
**答案：B**

5.条件语句中，布尔表达式必须返回什么类型？
A. int
B. boolean
C. String
D. Object
**答案：B**
