1. while 循环的循环体至少执行几次？
   A. 0 次
   B. 1 次
   C. 至少 1 次
   D. 无限次
   **答案：A**
2. do-while 循环的循环体至少执行几次？
   A. 0 次
   B. 1 次
   C. 至少 1 次
   D. 取决于条件
   **答案：B**
3. 以下哪个是增强 for 循环的正确语法？
   A. for (int i=0; i<arr.length; i++)
   B. for (int i : arr)
   C. for (i in arr)
   D. foreach (int i in arr)
   **答案：B**
4. 在循环中，break 语句的作用是？
   A. 跳过本次循环剩余语句，开始下一次迭代
   B. 退出当前循环
   C. 结束程序
   D. 继续执行循环
   **答案：B**
