1. Swing 是 Java 的什么工具包？
   A. 数据库连接
   B. 图形用户界面（GUI）
   C. 网络编程
   D. 多线程
   **答案：B**
2. 在 Swing 中，代表窗口的顶级容器类是？
   A. JPanel
   B. JFrame
   C. JDialog
   D. JApplet
   **答案：B**
3. 以下哪个组件用于显示单行文本输入框？
   A. JLabel
   B. JTextArea
   C. JTextField
   D. JPasswordField
   **答案：C**
4. 在 Swing 登录示例中，隐藏密码输入的组件是？
   A. JTextField
   B. JPasswordField
   C. JLabel
   D. JButton
   **答案：B**
5. 为了让 Swing 窗口关闭时退出程序，通常设置：
   A. frame.setSize()
   B. frame.setVisible(true)
   C. frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE)
   D. frame.pack()
   **答案：C**
