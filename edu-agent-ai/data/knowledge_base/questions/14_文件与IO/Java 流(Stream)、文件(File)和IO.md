1. 用于从文件读取字节数据的类是？
   A. FileReader
   B. FileInputStream
   C. BufferedReader
   D. InputStreamReader
   **答案：B**
2. 创建目录时，如果需要同时创建不存在的父目录，应该使用 File 类的哪个方法？
   A. mkdir()
   B. createDir()
   C. mkdirs()
   D. createNewFile()
   **答案：C**
3. 以下哪个类用于从控制台读取一行字符串？
   A. Scanner
   B. BufferedReader 的 readLine()
   C. System.in.read()
   D. A 和 B 都可以
   **答案：D**
4. 将字节流转换为字符流，通常使用哪个类作为桥梁？
   A. InputStreamReader / OutputStreamWriter
   B. FileReader / FileWriter
   C. BufferedInputStream / BufferedOutputStream
   D. DataInputStream / DataOutputStream
   **答案：A**
5. 以下哪个方法可以判断 File 对象是否为目录？
   A. isFile()
   B. isDirectory()
   C. exists()
   D. canRead()
   **答案：B**
