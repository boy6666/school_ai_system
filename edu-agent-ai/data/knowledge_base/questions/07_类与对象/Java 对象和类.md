1. 下列哪项是面向对象的三大特性之一？
   A. 模块化
   B. 继承
   C. 多文件
   D. 递归
   **答案：B**
2. 创建对象时使用哪个关键字？
   A. class
   B. new
   C. this
   D. super
   **答案：B**
3. 一个 Java 源文件中最多可以有几个 public 类？
   A. 0
   B. 1
   C. 2
   D. 任意多个
   **答案：B**
4. 以下哪个是构造方法的正确声明？
   A. void MyClass() { }
   B. MyClass() { }
   C. public MyClass() { }
   D. B 和 C 都是
   **答案：D**
5. 关于 this 关键字，说法正确的是？
   A. 可以用于引用当前对象
   B. 可以用于调用当前类的其他构造方法
   C. 在静态方法中不能使用
   D. 以上都对
   **答案：D**
