1. 所有异常类的父类是？
   A. Error
   B. Throwable
   C. Exception
   D. RuntimeException
   **答案：B**
2. 下列哪个是检查性异常（Checked Exception）？
   A. NullPointerException
   B. ArrayIndexOutOfBoundsException
   C. IOException
   D. ArithmeticException
   **答案：C**
3. 用于手动抛出异常的关键字是？
   A. throws
   B. throw
   C. try
   D. catch
   **答案：B**
4. 无论是否发生异常，一定执行的代码块由哪个关键字定义？
   A. catch
   B. finally
   C. final
   D. finalize
   **答案：B**
5. 从 Java 7 开始，可以在一个 catch 块中捕获多个异常，多个异常类型之间用下列哪个符号分隔？
   A. 逗号
   B. 分号
   C. 竖线（|）
   D. 与（&）
   **答案：C**
