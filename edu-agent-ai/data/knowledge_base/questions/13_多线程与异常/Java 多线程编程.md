1. 线程从新建状态进入就绪状态需要调用哪个方法？
   A. run()
   B. start()
   C. sleep()
   D. wait()
   **答案：B**
2. 以下哪个是创建线程的正确方式？
   A. 继承 Thread 类并重写 run() 方法
   B. 实现 Runnable 接口并实现 run() 方法
   C. 实现 Callable 接口
   D. 以上都是
   **答案：D**
3. 使当前线程暂停执行指定毫秒数的静态方法是？
   A. wait()
   B. join()
   C. sleep()
   D. yield()
   **答案：C**
4. 线程的优先级范围是？
   A. 0 ~ 10
   B. 1 ~ 10
   C. 0 ~ 100
   D. 1 ~ 100
   **答案：B**
5. 以下哪个关键字用于方法同步，保证线程安全？
   A. volatile
   B. transient
   C. synchronized
   D. static
   **答案：C**
