1. 下列哪种方式创建的字符串会存储在字符串常量池中？
   A. new String("hello")
   B. "hello"
   C. String.valueOf("hello")
   D. 以上都是
   **答案：B**
2. 获取字符串长度的正确方法是？
   A. length()
   B. getLength()
   C. length
   D. size()
   **答案：A**
3. 将字符串 "Hello" 和 "World" 连接，以下哪个效率较高？
   A. "Hello" + "World"
   B. "Hello".concat("World")
   C. new StringBuilder("Hello").append("World").toString()
   D. 三者效率近似
   **答案：A**
4. 以下哪个方法可以比较两个字符串内容是否相等（区分大小写）？
   A. equals()
   B. equalsIgnoreCase()
   C. compareTo()
   D. ==
   **答案：A**
5. String 类的特点是什么？
   A. 可变
   B. 不可变
   C. 线程不安全
   D. 可被继承
   **答案：B**
