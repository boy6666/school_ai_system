1. 声明数组的正确方式是？
   A. int[] arr;
   B. int arr[];
   C. 两者都正确
   D. 两者都错误
   **答案：C**
2. 创建数组 `int[] arr = new int[5];`，则 arr 的长度是多少？
   A. 4
   B. 5
   C. 6
   D. 不确定
   **答案：B**
3. 下列哪个方法可以对数组进行升序排序？
   A. Arrays.sort(arr)
   B. Arrays.order(arr)
   C. arr.sort()
   D. Collections.sort(arr)
   **答案：A**
4. 二维数组 `int[][] arr = new int[3][4];` 有多少个元素？
   A. 7
   B. 12
   C. 3
   D. 4
   **答案：B**
5. 增强 for 循环遍历数组时，不能直接做什么？
   A. 读取元素值
   B. 修改数组元素（基本类型）
   C. 遍历所有元素
   D. 使用 break
   **答案：B**
