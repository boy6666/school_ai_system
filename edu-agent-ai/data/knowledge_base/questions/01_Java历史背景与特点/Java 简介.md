**1. Java 最初是由哪家公司发布的？**
A. Microsoft
B. Oracle
C. Sun Microsystems
D. IBM
**答案：C**
解析：Java 由 Sun Microsystems 于 1995 年推出，后来被 Oracle 收购。

**2. 以下哪个是 Java 平台标准版的正确缩写？**
A. J2EE
B. Java ME
C. Java SE
D. Java EE
**答案：C**
解析：Java SE 是标准版，曾用名 J2SE，2005 年后更名为 Java SE。

**3 .关于 Java 语言特性，下列说法错误的是？**
A. Java 支持多继承（类之间）
B. Java 提供了自动垃圾回收
C. Java 是面向对象的语言
D. Java 支持多线程
**答案：A**
解析：Java 类只支持单继承，但接口支持多继承。

**4. Java 程序运行时的字节码文件扩展名是什么？**
A. .java
B. .class
C. .exe
D. .jar
**答案：B**
解析：.java 源文件编译后生成 .class 字节码文件。

**5. JDK 1.5 被更名为？**
A. Java SE 6
B. Java SE 5.0
C. Java SE 7
D. Java SE 8
**答案：B**
解析：J2SE 1.5 更名为 Java SE 5.0 以强调其重要性。
