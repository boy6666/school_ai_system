**1.在 Windows 中配置 Java 环境变量时，通常需要设置以下哪个变量指向 JDK 安装路径？**
A. PATH
B. CLASSPATH
C. JAVA_HOME
D. JRE_HOME
**答案：C**
解析：JAVA_HOME 通常指向 JDK 安装目录，供其他工具使用。

**2.使用命令行检查 Java 是否安装成功，应输入哪个命令？**
A. java --version
B. javac --version
C. java -version
D. both A and C
**答案：C**
解析：java -version 是常用命令；javac -version 检查编译器。

**3. 以下哪个是开源免费的 Java IDE？**
A. IntelliJ IDEA (Ultimate)
B. Eclipse
C. Visual Studio Code (需插件)
D. NetBeans
**答案：B, D (多选? 但单选题环境下选最常见的 Eclipse)**
本题若为单选，常见标准答案是 Eclipse 或 NetBeans。按常见教材，Eclipse 是典型开源 IDE。
**答案：B**

**4. 在 IntelliJ IDEA 中创建第一个 Java 项目时，需要选择什么来提供 Java 开发工具包？**
A. JRE
B. JDK
C. JVM
D. JIT
**答案：B**
解析：JDK (Java Development Kit) 包含编译器、运行时等。

**5. 关于 CLASSPATH 环境变量，JDK 1.5 以上版本的要求是？**
A. 必须手动设置
B. 不需要设置也可编译运行
C. 只能设置为当前目录
D. 必须设置为 JDK 的 lib 目录
**答案：B**
解析：JDK 1.5 及以上版本，默认会搜索当前目录和核心类库，不强制设置 CLASSPATH。
