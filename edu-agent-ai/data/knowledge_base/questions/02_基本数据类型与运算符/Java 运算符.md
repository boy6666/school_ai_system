**1. 下列代码输出结果是什么？**

java

```
int a = 5, b = 2;
System.out.println(a / b);
```



A. 2.5
B. 2
C. 2.0
D. 3
**答案：B**
解析：整数除法结果为整数，舍去小数部分。

**2. 以下哪个是逻辑与运算符？**
A. &
B. &&
C. |
D. ||
**答案：B**
解析：&& 是逻辑与，支持短路；& 是按位与。

**3. 表达式 (3 > 2) ? 10 : 20 的结果是？**
A. 10
B. 20
C. true
D. false
**答案：A**
解析：条件运算符，条件成立返回第一个值。

**4.位运算符中，哪个是按位异或？**
A. &
B. |
C. ^
D. ~
**答案：C**
解析：^ 是异或，相同为0，不同为1。

**5. 以下代码执行后，x 的值是多少？**

java

```
int x = 10;
x += 5;
```



A. 10
B. 15
C. 5
D. 105
**答案：B**
解析：+= 为赋值运算符，等价于 x = x + 5。
