1. 方法的返回值类型为 void 表示？
   A. 返回 null
   B. 不返回任何值
   C. 返回 0
   D. 返回空字符串
   **答案：B**
2. 以下哪个是方法重载的正确条件？
   A. 方法名相同，返回类型不同
   B. 方法名相同，参数列表不同
   C. 方法名相同，修饰符不同
   D. 方法名相同，参数名不同
   **答案：B**
3. 在 Java 中，命令行参数通过哪个数组传递给 main 方法？
   A. String[] args
   B. int[] args
   C. String args
   D. Object[] args
   **答案：A**
4. 关于可变参数（varargs），正确的是？
   A. 一个方法可以有多个可变参数
   B. 可变参数必须放在参数列表最后
   C. 可变参数不能为 null
   D. 可变参数只能用于 int 类型
   **答案：B**
5. 以下哪个是构造方法的特性？
   A. 有返回值类型
   B. 方法名与类名不同
   C. 在 new 对象时自动调用
   D. 必须显式调用
   **答案：C**
