# EduAgent 网站启动完整指南

## 环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 1.8+ | `java -version` 确认 |
| Maven | 3.6+ | `mvn -version` 确认 |
| MySQL | 8.0+ | 需启动服务 |
| Python | 3.10+ | AI 引擎运行环境 |
| Node.js | 18+ LTS | 前端构建（可选，dist 已提供） |
| Git | 任意版本 | 代码版本管理 |

## 一、数据库初始化

### 1.1 启动 MySQL

```bash
# Windows 服务方式
net start MySQL80
```

### 1.2 执行建库脚本

```bash
cd E:\college_information\edu-agent

# 1. 创建数据库
mysql -u root -p < database\init.sql

# 2. 建表
mysql -u root -p < database\table.sql

# 3. 导入演示数据（可选）
mysql -u root -p < database\mock-data.sql
```

### 1.3 验证

```sql
mysql -u root -p -e "USE edu_agent; SHOW TABLES;"
```

应看到：`users`, `student_profiles`, `resources`, `learning_tasks`, `practice_questions`, `conversation` 等表。

|--------|------|------|

## 二、AI 引擎启动

### 2.1 配置 API Key

编辑 `edu-agent-ai\.env`：

```env
MOCK_LLM=0
MODEL_NAME=deepseek-v4-pro
BASE_URL=https://api.deepseek.com
API_KEY=sk-你的DeepSeek-API-Key
TEMPERATURE=0.2
MAX_TOKENS=1200
AGENT_DEBUG=0
```

### 2.2 安装依赖并启动

```bash
cd E:\college_information\edu-agent\edu-agent-ai
pip install -r requirements.txt
uvicorn api:app --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。

### 2.3 验证

```bash
curl http://localhost:8000/health
# 返回 {"status":"ok"}
```

## 三、后端启动

### 3.1 配置数据库连接

编辑 `edu-agent-server\src\main\resources\application-dev.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/edu_agent?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 你的MySQL密码
```

### 3.2 启动

```bash
cd E:\college_information\edu-agent\edu-agent-server
mvn spring-boot:run
```

看到 `Started EduAgentApplication in X seconds` 即成功。

首次启动 Maven 会下载依赖（约 3-5 分钟），之后启动只需几秒。

### 3.3 验证

```bash
curl -X POST http://localhost:8080/auth/login ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```

返回 Token 即成功。

## 四、前端启动

### 4.1 开发模式（Vite 热更新）

```bash
cd E:\college_information\edu-agent\edu-agent-web
npm install          # 首次需要
npm run dev
```

浏览器打开 `http://localhost:5173`

### 4.2 生产模式（Nginx 托管）

前端已打包在 `edu-agent-web\dist\`，直接配置 Nginx：

```nginx
server {
    listen 80;
    server_name localhost;

    location / {
        root E:/college_information/edu-agent/edu-agent-web/dist;
        try_files $uri /index.html;
    }

    location /api/ {
        proxy_pass http://localhost:8080/;
    }

    location /uploads/ {
        alias E:/college_information/edu-agent/uploads/;
    }
}
```

## 五、完整启动顺序

```text
1. MySQL           (端口 3306)
2. Python AI       (端口 8000)   cd edu-agent-ai && uvicorn api:app --port 8000
3. Spring Boot     (端口 8080)   cd edu-agent-server && mvn spring-boot:run
4. Vue 前端        (端口 5173)   cd edu-agent-web && npm run dev
   或 Nginx        (端口 80)     配置后 start nginx
```

**一键启动脚本** `start-all.bat`（放在 `E:\college_information\edu-agent\`）：

```batch
@echo off
echo === Starting EduAgent ===

echo [1/3] Starting AI Engine...
start "AI-Engine" cmd /c "cd edu-agent-ai && uvicorn api:app --port 8000"

echo [2/3] Starting Backend...
start "Backend" cmd /c "cd edu-agent-server && mvn spring-boot:run"

echo [3/3] Starting Frontend...
start "Frontend" cmd /c "cd edu-agent-web && npm run dev"

echo === All services starting... ===
echo MySQL must be running already!
echo Frontend: http://localhost:5173
echo Backend:  http://localhost:8080
echo AI:       http://localhost:8000/health
pause
```

## 七、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 端口 8080 被占用 | 上次未正常关闭 | `netstat -ano \| findstr 8080` 然后 `taskkill /PID xxx /F` |
| 数据库连接失败 | MySQL 未启动或密码错误 | 检查 `application-dev.yml` 密码 |
| AI 调用超时 | Python 引擎未启动 | 确认 `uvicorn api:app --port 8000` 在运行 |
| 前端请求 401 | Token 过期 | 重新登录获取新 Token |
| Maven 下载慢 | 网络问题 | 已配置阿里云镜像（aliyunmaven） |
