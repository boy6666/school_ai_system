## 二、测试

### 2.1 命令行快速验证


## 四、常见问题

| 现象 | 解决 |
|------|------|
| 后端报 `Unknown database` | `net start MySQL80` 确认 MySQL 已启动 |
| 后端报 class version 52.0 | 检查 `JAVA_HOME` 指向 JDK 25 |
| 登录返回 401 | 数据库密码哈希过期，重新生成 BCrypt 哈希更新 `users` 表 |
| AI 对话返回 `【模拟大模型输出】` | 确认 `edu-agent-ai/.env` 中 `USE_MOCK_LLM=0` |
| 前端页面空白 | `cd edu-agent-web && npm install` |
| 端口被占用 | `netstat -ano \| findstr <端口>` → `taskkill /PID xxx /F` |
