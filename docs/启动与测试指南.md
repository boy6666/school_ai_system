# EduAgent 后端启动与测试指南

> 适用环境：Windows + JDK 25 + MySQL 8.0 + Maven 3.9.12

---

## 一、环境准备

### 1.1 确认 MySQL 运行

```bash
net start MySQL80
```

> **为什么？** 所有业务数据（用户、题目、资源等）存储在 MySQL `edu_agent` 库中。MySQL 未启动会导致后端连不上数据库，直接启动失败。

验证：

```bash
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p123456 -e "USE edu_agent; SHOW TABLES;"
```

应看到 `users`、`resources`、`practice_questions` 等 20+ 张表。如果没有，说明数据库未初始化，需要先导入 `database/` 目录下的 SQL 脚本。

### 1.2 确认 JDK 版本

```bash
"C:\Users\Lenovo\.jdks\openjdk-25.0.1\bin\java" -version
```

应输出 `openjdk version "25.0.1"`。

> **为什么？** Spring Boot 3.4.1 要求 Java 17+。你电脑默认的 Java 8 无法编译运行。JDK 25 位于 `C:\Users\Lenovo\.jdks\openjdk-25.0.1`。

## 二、启动后端

打开一个新终端（CMD 或 PowerShell），逐行执行：

```bash
set JAVA_HOME=C:\Users\Lenovo\.jdks\openjdk-25.0.1
cd D:\AAA_Projects\school_ai_system-main (1)\school_ai_system-main\edu-agent-server
C:\Users\Lenovo\.m2\wrapper\dists\apache-maven-3.9.12-bin\5nmfsn99br87k5d4ajlekdq10k\apache-maven-3.9.12\bin\mvn spring-boot:run
```

**逐行解释：**

| 行 | 作用 | 为什么 |
|----|------|--------|
| 第 1 行 | 设置 `JAVA_HOME` 指向 JDK 25 | 覆盖系统默认的 Java 8，让 Maven 用 JDK 25 编译 |
| 第 2 行 | 进入后端项目目录 | `pom.xml` 在此目录，Maven 需要在项目根目录执行 |
| 第 3 行 | 用 Maven wrapper 启动 Spring Boot | `spring-boot:run` 是 Spring Boot 插件命令，自动编译 + 运行 |

**启动成功标志：** 看到终端输出 `Started EduAgentApplication in X seconds`。

后端运行在 `http://localhost:8080`，context-path 为 `/api`，即所有接口路径前要加 `/api`。

> **注意：** 终端窗口**不能关**。关闭窗口 = 进程结束 = 后端停止。按 `Ctrl+C` 可正常退出。

## 三、测试接口（命令行验证）

启动后端后，另开一个终端，按以下顺序逐条执行。

### 3.1 登录（获取 Token）

```bash
curl -s -X POST http://localhost:8080/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```

> **为什么先测这个？** 系统采用 JWT 鉴权，后续所有接口都需要在请求头中携带 Token。登录就是获取 Token 的唯一入口。

**预期结果：** `"code":200`，返回 `"token":"eyJ..."` 字样。

**如果失败：**

- 返回 `401 用户名或密码错误` → 数据库 `users` 表中密码哈希与 `admin123` 不匹配，需重新生成 BCrypt 哈希并更新
- 返回 `Connection refused` → 后端没启动或崩溃了

### 3.2 管理后台-用户列表

```bash
curl -s http://localhost:8080/api/admin/users -H "Authorization: Bearer 你的token"
```

> **为什么测这个？** 这是管理后台核心读接口，能同时验证：JWT 鉴权是否生效、数据库连接是否正常、JSON 序列化是否正确。

**预期结果：** `"code":200`，`"total":8`，`"list"` 中包含 admin/teacher001/student001 等用户。

### 3.3 管理后台-Agent 列表

```bash
curl -s http://localhost:8080/api/admin/agents -H "Authorization: Bearer 你的token"
```

> **为什么测这个？** 这是纯内存 Mock 数据（不查数据库），用于隔离排查：如果这个通了但用户列表不通，说明问题在数据库层。

**预期结果：** `"code":200`，返回 ProfileAgent、TutorAgent、QuizAgent 共 3 个 Agent。

### 3.4 学生登录

```bash
curl -s -X POST http://localhost:8080/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"student001\",\"password\":\"admin123\"}"
```

> **为什么测这个？** 验证不同角色（student/admin/teacher）的登录都能正常工作。

**预期结果：** `"code":200`，`"role":"student"`。

## 四、启动前端（页面验收）

### 4.1 启动

另开一个终端（后端终端别关）：

```bash
cd D:\AAA_Projects\school_ai_system-main (1)\school_ai_system-main\edu-agent-web
npm install
npm run dev
```

> **为什么 `npm install` ？** 首次启动需要安装 Vue/Element Plus/ECharts 等依赖。之后启动只需 `npm run dev`。

浏览器打开 **http://localhost:5173**。

> **为什么前端能请求到后端？** `vite.config.ts` 中配置了代理规则：前端发起的 `/api/**` 请求会被 Vite Dev Server 自动转发到 `http://localhost:8080`。前端不需要写死后端地址，避免了跨域问题。

### 4.2 登录验证

| 用户名 | 密码 | 角色 | 预期效果 |
|--------|------|------|----------|
| admin | admin123 | 管理员 | 进入管理后台，可看到 Dashboard/用户管理/资源管理等菜单 |
| student001 | admin123 | 学生 | 进入学生端，可看到学习辅导/资源/任务等界面 |

## 五、完整启动顺序

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│  MySQL   │ → │  后端     │ → │  前端     │
│ 端口3306 │   │ 端口8080 │   │ 端口5173 │
└──────────┘    └──────────┘    └──────────┘
```

启动顺序**不能乱**：先有数据库 → 后端才能连上 → 前端的 API 代理才有地方转发。

## 六、一键启动脚本（可选）

将以下内容保存为 `start-all.bat` 放在项目根目录，双击即可启动全部服务：

```batch

echo === Starting complete ===
echo Backend:  http://localhost:8080/api
echo Frontend: http://localhost:5173
pause
```

## 七、常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 后端启动报 `Unknown database 'edu_agent'` | MySQL 未启动或数据库未创建 | `net start MySQL80`，确认数据库存在 |
| 后端启动报 class version 61.0/52.0 | 使用了 Java 8 | 检查 `JAVA_HOME` 是否指向 JDK 25 |
| 登录返回 `401 用户名或密码错误` | 密码哈希不匹配 | 重新生成 BCrypt 哈希并更新 `users` 表 |
| 前端 API 请求 404 | 后端未启动或代理配置错误 | 确认后端终端在跑，检查 `vite.config.ts` |
| 端口 8080 被占用 | 上次未正常关闭 | `netstat -ano \| findstr 8080` 找 PID，`taskkill /PID xxx /F` |
| 前端页面空白 | 依赖未安装 | 进入 `edu-agent-web` 目录执行 `npm install` |
| `mvn` 命令找不到 | Maven 不在系统 PATH | 使用完整路径 `C:\Users\Lenovo\.m2\wrapper\...\mvn` |
